# ASP.NET Core Web API – .NET 8.0 with SQLite

This is an ASP.NET Core Web API built with .NET 8.0 and uses SQLite as the database via Entity Framework Core.

## Technology Choices & Reasoning

| Technology               | Reason                                                                |
|--------------------------|-----------------------------------------------------------------------|
| **Entity Framework Core**| Simplifies database interactions with LINQ and code-first migrations. |
| **SQLite**               | Lightweight, file-based DB—ideal for local dev and small-scale apps.  |
| **Visual Studio 2022**   | Rich development environment with strong support for .NET and EF Core.|
